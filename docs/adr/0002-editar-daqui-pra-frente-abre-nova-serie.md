# "Editar este e os próximos" encerra a série e abre outra

Mudar uma série a partir de um mês encerra a série no mês anterior e cria uma nova série a partir do mês editado, em vez de alterar a série existente. Assim o histórico guarda quando e para quanto o valor mudou (ex.: aluguel reajustado), os meses passados nunca são reescritos e cada série tem um único valor de partida. Decidido na sessão do ticket 14 (2026-10-18).
