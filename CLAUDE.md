## Agent skills

### Issue tracker

Issues e specs ficam como arquivos markdown em `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Labels padrão (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix), registrados numa linha `Status:` em cada issue. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `GLOSSARY.md` + `docs/adr/` na raiz do repo. See `docs/agents/domain.md`.
